# 课表时间说明与公式渲染

基于已有图片周课表和统一 MathMarkdown 继续修复，保留原来的课表模型，不新增自动周展开。

图片识别新增可选 `timeText`、`weekText`，各最多 200 字：分别保存该课程在原图中可见的时刻/作息对照，以及起止周/单双周等限制。未知内容留空，不能由节次猜钟点。字段通过模型结果白名单进入草稿，在周表、列表及教材课次标签展示，可手动核对修改后保存；JSON 存储兼容旧条目。

这些说明只用于核对，不换算日历日期，也不证明模型读对了原图。存在非空 weekText 时不自动选择智云课堂回放，仍可核对后手动选择。请求期间修改周次、星期、节次、日期或已选回放时，迟到响应不能覆盖新选择。旧条目缺少 weekText 不代表已证明每周授课；保留此前匹配行为。

文字课表 AI 解析额外核对给定课程目录/课次归属、IANA 时区及结束时刻的实际偏移（含 DST）；手工保存空结束时间的行为不变。图片草稿仍允许未关联课程、未知节次，不强行补齐。视觉工具提示模型按行列、覆盖节次和周次解释，不把视频定位秒数当上课时间。

共享 MathMarkdown 已有美元公式渲染，此次补充闭合的 `\(...\)`、`\[...\]` 及常见货币保护。历史消息、流式回复和其它已接入该组件的 AI 文本共用处理。未闭合片段待补全后渲染；原文存储和复制不变。独立 CommonMark parser 保护嵌套代码、链接 URL/标题、图片 alt、HTML 和定义的范围，再归一正文。链接文字中的反斜杠公式采取保守保留。KaTeX 不启用 trust，不执行原始 HTML，安全外链 overrides 和 inline 模式保留。

闭合的 `math`、`latex`、`tex`、`katex` 围栏块表达数学意图：裸 LaTeX 交给 KaTeX；存在独立完整分隔符公式行/段时，逐段渲染，剩余行继续作为代码保留（如两行公式后跟普通长代码行）。无语言标签只识别独立完整公式，明显程序块保持原样。`js`、`python` 等其它语言及缩进代码不转数学。行内反引号内容若整体是完整数学分隔符表达式，则渲染为行内公式；真实程序、金额及不完整数学表达式继续显示代码原文。未闭合围栏/分隔符在流式期间保持原文；闭合后再渲染。多行分隔符支持独立成行的 `$$` 或 `\[`/`\]`；带分隔符与普通文字混排的同一行保守保留。显式数学标签应仅用于数学内容；无效 LaTeX 显示 KaTeX 可见错误，不隐去正文。

KaTeX 样式依赖精确固定为 `0.16.47`，与 rehype-katex 实际渲染器一致，并用版本一致性测试防止再次错配。此前直接引入的 `0.19.1` 样式使用新类名，无法匹配 `0.16.47` 渲染器生成的上标缩放等类名，造成上标与正文同大以及公式几何错误；对齐后上标按官方样式缩为 0.7em。受控浏览器同时检查字体加载、实际公式与仅官方对应版本样式的参考几何，以及分数、上下标和矩阵的浅深主题显示。

测试覆盖图片 HTTP 字节/视觉模型、timeText/weekText 草稿到保存回读、格式及长度校验、DST、真实渲染器和延迟回放响应。隐藏浏览器使用实际 UI 与本地 stub；它不证明 OCR 或模型准确率。缺用户原图和实际运行版本，仍需真实课表（合并格、时刻表、单双周）验收；不声称三个入口的真实识别质量全部解决。
