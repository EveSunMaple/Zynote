# 架构与模块边界

React 页面通过隔离 preload 桥访问登记过的 IPC action。Electron 主进程只负责窗口、生命周期、原生对话框、系统加密（safeStorage/DPAPI）、智云 `WebContentsView`、SnapAny 隐藏窗口与 Go core 监管；业务规则、持久化、网络与任务编排由 Go core（JSON-RPC 2.0 over stdio）承担，重原生模块由 Rust `zynote-native` 以独立进程提供。不启动 Python、yt-dlp 或 BiliSum 网页服务器。

知识库由 Go `internal/knowledge` 管理，使用 knowledge-native.sqlite、中文全文与本地 BGE ONNX。研究直接绑定知识库来源代际和正文哈希；旧 JSON/SQLite 只读建立基线。旧工作流只展示历史结果，继续分析必须绑定当前来源。

媒体下载由 Go `internal/media` 管理：各平台原生目录、ETag/范围/哈希断点及原生并行传输；FFmpeg 只处理本任务下载到本地的文件，进程组取消与退出由 Go 管理。结果时长、画面、音轨、字幕和哈希通过后，才清理任务中间文件。

登录档案与媒体/通讯凭据由 Go 服务管理，密文经反向 `crypto.*` 壳服务调用 Electron `safeStorage`（Windows 兼容 DPAPI 旧信封）；密文不会导出为 Cookie 临时文件。下载元数据及媒体请求按目标域匹配，加密任务记录恢复与成果核验仍走同一队列。

ASR 由 Go `internal/asr` 调 Rust `zynote-native --mode asr`，使用本地 Whisper/Silero ONNX。PDF 文本/批注、二维码、来源和导出均在 Rust/Go 原生逻辑内完成。FFmpeg、SQLite、ONNX、Electron 与模型连接 CLI 是独立第三方组件。

主窗口禁用 nodeIntegration，开启 contextIsolation/sandbox，仅允许主框架调用已登记 IPC。每个 action 在 `contract/actions.json` 标注 `go` 或 `shell`；窗口与文件选择等壳动作留在 Electron，其余经 `GoCore` 转发。

目录按职责组织：`src/main` 下 `app`（窗口/诊断）、`backend`（GoCore、portable 路径、shell services）、`media/sources`（SnapAny 壳）、`security`（系统加密）与 `zhiyun`（登录视图）；Go 业务位于 `backend/internal/<域>`，Rust helper 位于 `native/zynote-native`；渲染层 `src/renderer/src` 下 `app`（壳与标题栏）、`features/<域>`、`ui`（跨域组件）、`lib`、`styles`、`assets`；`src/shared` 只放协议与纯函数。跨目录引用统一使用 `@main/*`、`@renderer/*`、`@shared/*` 别名，禁止跨目录相对路径。

前端使用 HeroUI v3（`@heroui/react` + `@heroui/styles`）与 Tailwind CSS 4，样式层顺序固定为 `legacy → theme → base → components → utilities`；交互控件使用 HeroUI React 组件，语义变量映射到现有调色板，图标使用 lucide-react。整页功能窗口共用 `ui/WindowPanel`（统一 280px 左菜单、窄屏 240px、内容区 32/40 间距与页头节奏），设置类界面集中在 `features/settings/SettingsHub`，入口固定在左侧栏底部的设置按钮。主窗口为自绘标题栏：Windows/Linux 使用 `frame: false`，macOS 使用 `hiddenInset` 保留红绿灯；最小化/最大化/关闭通过 `window:*` 壳动作执行，最大化状态经事件通道同步。

课程、知识库、研究、通讯和下载各自管理持久事务与取消；成果必须核验，模型未知结果不自动重试。关闭应用先停止所属 Go/Rust 子进程，不强制结束用户的其它应用。P7 后不再保留 TypeScript 业务后端或回退开关。
